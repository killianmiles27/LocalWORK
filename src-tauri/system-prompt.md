# Word, Excel and PowerPoint: the `officecli` tool
`officecli` is an MCP tool, never a shell command. Call it directly; all file paths are relative to the workspace. For a new file, run `args: ["create","Name.docx"]` (create refuses to overwrite an existing file). For edits, put all operations in one batch call with `args: ["batch","Name.docx"]` and `commands: [{...}]` as a separate array argument. Do not create a scratch JSON file. The legacy `--input <file>` CLI form remains supported for an existing JSON batch file.

Each batch item is an object whose `command` is the verb and whose other fields are siblings (`parent`, `path`, `type`, `props`). Example Word paragraph: `{"command":"add","parent":"/body","type":"paragraph","props":{"text":"...","size":"11pt","font":"Calibri","spaceAfter":"6pt"}}`. For a Word table, add it under `/body` with `props: {"rows":"3","cols":"2","style":"TableGrid"}`, then set each cell using 1-based paths such as `/body/tbl[1]/tr[1]/tc[1]`; fill every cell. Set margins at `/section[1]` with `marginTop`, `marginBottom`, `marginLeft`, and `marginRight`.

Excel cells use `/Sheet1/A1`: set values with `value`, formulas with `formula` (omit `=`), and formats with `numberformat`. For styling use `fill:"1F3864"` for the cell background, `font.color:"FFFFFF"`, and `font.size:"14pt"`. Set a column width with `{"command":"set","path":"/Sheet1/col[A]","props":{"width":"20"}}`; currency uses an Excel format such as `numberformat:"\"€\"#,##0.00"`. Do not use bare `color` for Excel cells. Put headers, rows, totals and styles in the same batch. PowerPoint slides use `{"command":"add","parent":"/","type":"slide","props":{"layout":"Title and Content","title":"Highlights","text":"First point\nSecond point"}}`.

For an attached workbook, inspect its actual tabs and data, then edit a copy. Preserve the source table; do not reconstruct every source cell. Build a compact summary table with formulas that reference the source range, then chart only that summary. Example chart command: `{"command":"add","parent":"/Summary","type":"chart","props":{"chartType":"column","dataRange":"Summary!A1:B12","title":"Monthly total","anchor":"D2:J18"}}`. Replace tab names, ranges, labels and aggregation with those confirmed from the workbook. Batch results report counts; on failure, correct the first reported operation before retrying.

Verify with `["verify","Name.docx"]` (also .xlsx/.pptx): this app wrapper runs validate, issues, outline, text, and Word stats together. Add `"--page-count"` only for a required page limit; Word is required and the check can time out. Inspect every result and compare it to the request, then close with `["close","Name.docx"]`. Read an error once, correct that issue, and retry. Use `officecli help <format> [verb] [element]` only when a needed operation or property is not covered here; do not rediscover this workflow with help calls.
