---
name: research
description: Answer questions that need evidence from the web, with cited sources
---
1. Identify the claims that need evidence, then use targeted web_search queries. Prefer official, primary and appropriately current sources. Match research depth to the user's request; there is no mandatory number of queries or pages unless the user specifies one.
2. web_fetch the best sources. Request a focused excerpt with max_chars, and increase it when necessary to read the relevant evidence. If a page fails or contains little useful content, choose another source. Do not keep fetching the same page to recover details already in a saved result.
3. Write down each claim with its source URL and date. Separate what a source says from your own inference, and label the inference.
4. If sources disagree, say so and name both. If you found nothing solid, say that. Never invent a source, number or quote.
5. Stop researching when the required claims are supported and material contradictions are resolved. Keep source links and notes for reuse. Cite the retrieved sources in the user's requested format; do not add unrequested sections to a deliverable.
