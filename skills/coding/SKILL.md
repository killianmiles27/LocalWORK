---
name: coding
description: Make code changes safely inside the workspace
---
1. Inspect first: list files, read the relevant ones, find existing conventions. Do not guess at structure.
2. State a short plan before changing more than 3 files.
3. Make small edits, then run the build or tests after each batch.
4. If the same failure happens 3 times, stop, summarise what you tried, and ask.
5. Never run installs, network downloads or deletes without the user's approval. Keep changes inside the workspace.
