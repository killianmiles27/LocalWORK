# LocalWORK plugins

The official plugins moved to their own repository: **[killianmiles27/LocalWORK-plugins](https://github.com/killianmiles27/LocalWORK-plugins)**.

Install them in the app from Settings → Plugins → *Get plugins*, where that repository is listed as *Official*. You can add any other public GitHub repository of plugins there too. To write one, see [docs/PLUGINS.md](../docs/PLUGINS.md).
