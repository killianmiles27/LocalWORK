# LocalWORK 0.1.2 — Alpha

- A small ALPHA badge beside the sidebar app name identifies the current development stage.
- Edit text and cells directly in current Word, Excel and PowerPoint previews, while retaining selection notes for the assistant. Historical revisions remain read-only.
- Zoom Office previews with the controls, Ctrl+mouse wheel, Ctrl +/- and Ctrl+0.
- Saved pane edits trigger a same-project AI dependency check after a short pause. It waits for the selected chat and model, preserves composer drafts, and asks about ambiguous relationships.
- OfficeCLI has a compact built-in recipe with verified spreadsheet styling syntax. Batches normally use inline commands; large batches clean up hidden temporary inputs. Legacy hidden build JSON files stay out of the picker.
- Updated the dependency notice inventory, including the missing upstream remark-math license text.

Related-file checks depend on the model's judgment and should be reviewed. Pending checks are held in memory while the app is open; changes made in external Office applications do not trigger them. This release has not been certified on a clean Windows account or VM.

Local verification includes the frontend/release build, Node/Python/Rust regressions, isolated browser interactions, and the real bundled OfficeCLI preview and large-batch checks. Model reasoning quality is not established by these tests.

Windows acceptance checks passed for automatic-mode persistence, bounded Stop/resume, and context display. The checks now wait for settings hydration and match the current live-context wording.

Dependency audits still report ZIP extraction advisories (RUSTSEC-2026-0367/0368/0369) and the transitive KaTeX advisory GHSA-238p-pmpm-9mq7. LocalWORK's plugin importer reads bounded entries manually and does not call the affected archive extraction APIs; math output uses Temml rather than KaTeX. These are outstanding dependency findings, not a clean audit or a guarantee against all related issues. Browser and pinned Python advisory checks passed.
