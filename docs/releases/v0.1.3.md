# LocalWORK 0.1.3

Still alpha. This update is about getting work finished and making failures easier to understand.

## Changes

- Spreadsheet attachments start with a compact profile instead of dumping every cell. Reusable tools inspect tables, aggregate data, read evaluated Excel ranges and compare results without retyping them into scripts.
- Word and Excel recipes build formatted documents, tables, live formulas and charts. Source files are preserved, existing targets are refused, and changed sources invalidate saved comparisons.
- Python commands no longer inherit the agent input pipe, which could make simple scripts hang.
- Output limits and repeated reasoning get bounded recovery with tools still available. Context compaction can checkpoint a long first turn and continue. Unfinished work stays visibly incomplete.
- Plans show paused when a run stops and receive reminders to reflect verified progress. Routine execution can use lower reasoning effort without changing model profiles.
- Chat downloads include saved thinking, tool diagnostics and request timing/token measurements. Live thinking follows new output until you scroll up.
- Manual document edits accumulate for an explicit Check related files action. Saving alone does not start another model run.

## Download

Use the Windows x64 setup executable. The installer contains the app and its tools, not model weights or plugins. Install extras from Settings > Plugins > Get plugins, or import the separate plugin ZIPs below.

## Known limits

This is vibe-coded slop and it is still alpha. Check generated calculations, claims and documents. The new workflow tools passed deterministic and real OfficeCLI checks; that does not establish a real-model speedup or guarantee task completion.

Windows is the supported platform. Model requirements depend on the model/server you choose. Office previews approximate layout; exact Word page counts require Word. Tools run with your user permissions, and approval checks are not an OS sandbox. Network tools use the network even though model inference is local.

A clean Windows account/VM install and a full automatic updater install were not exercised for this release. Dependency advisory findings and test details are recorded in [PUBLIC_READINESS.md](https://github.com/killianmiles27/LocalWORK/blob/v0.1.3/docs/PUBLIC_READINESS.md). The updater signature is separate from Windows Authenticode signing.
