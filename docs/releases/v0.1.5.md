# LocalWORK 0.1.5

Still alpha. This release adds Linux.

## Changes

- Linux x64 builds: an AppImage that updates itself, a .deb for Ubuntu, Debian and Mint, an .rpm for Fedora and openSUSE, and a PKGBUILD for Arch-based distributions. They bundle the same tools as the Windows installer: the patched agent, OfficeCLI, Node, Playwright with headless Chromium, whisper.cpp with its voice model, and the web tool libraries for Python 3.11 to 3.14.
- Model processes and tools are started in their own process group on Linux and stopped as a group, so closing the app does not leave a model loaded.
- The approval checks understand Linux shells. Automatic mode still asks before `sudo` and other privilege tools, autostart files, enabling systemd units, cron jobs, and publishing commands run through `bash -c`. Step-by-step mode also asks before commands that touch paths outside the working folder (including `~`), package managers (apt, pacman, yay, dnf and others) and SSH. System folders such as `/etc` and `/usr` and the app's own data folder are always blocked for file tools.
- Pinned KaTeX 0.18.11 to clear a low-severity advisory in the math rendering dependency.

## Download

- Windows x64: the setup executable.
- Linux x64: the AppImage (`chmod +x`, then run it), the .deb (`sudo apt install ./LocalWORK_0.1.5_amd64.deb`), or the .rpm (`sudo dnf install ./LocalWORK-0.1.5-1.x86_64.rpm`).
- Arch, Manjaro, EndeavourOS: put the PKGBUILD in an empty folder and run `makepkg -si`.

The packages contain the app and its tools, not model weights or plugins. Install extras from Settings > Plugins > Get plugins, or import the separate plugin ZIPs below. Only the Windows installer and the AppImage update from inside the app; for the .deb, .rpm and Arch package, install the next release over it.

## Known limits

This is vibe-coded slop and it is still alpha. Check generated calculations, claims and documents.

The Linux packages are built and checked in CI (Ubuntu 22.04), and the Linux unit tests pass there. They have not yet been run on a real Linux desktop with a live model, so expect rough edges and please report them. The AppImage needs FUSE 2. Rollback to an earlier version is Windows-only. Strata or PolyStrata must be set up for Linux; its folder needs `serve/server.py` and `.venv/bin/python`.

Tools run with your user permissions, and approval checks are not an OS sandbox. Network tools use the network even though model inference is local. The updater signature is separate from Windows Authenticode signing.
